## 2024-05-18 - Porting C pointer math safely to Rust
**Learning:** When porting C code that incrementally advances a pointer over a string while parsing tokens (like `fscanf` doing `%s` or iterating over char arrays for `.`, `%`, and `k` delimiters), using a manual parser struct wrapping a byte slice `&[u8]` and maintaining a `pos: usize` cursor provides an idiomatic, high-performance alternative to heap-allocating `String` manipulations or multiple regex passes. It allows zero-copy tokenization matching C speeds while adhering to Rust safety guarantees.
**Action:** Always maintain bounds checking (`self.pos < self.input.len()`) and use `std::str::from_utf8(&self.input[start..end]).ok()` to bridge byte slices back to expected strings for number parsing or matching logic.
